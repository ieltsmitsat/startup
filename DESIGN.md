# StudentHub Design System (DESIGN.md)

## 1. Aesthetic World & Identity
* **Philosophy:** Modern Academic & Tech (Linear + Notion + Stanford style).
* **Atmosphere:** Serious academic credibility, precision-engineered, developer-grade clarity, no superfluous decoration.
* **Palette:**
  - **Light Mode (Polar White):**
    - Background: `#f8fafc` (slate-50) / `#ffffff`
    - Surface Card: `#ffffff`
    - Borders: `#e2e8f0` (slate-200)
    - Primary Text: `#0f172a` (slate-900)
    - Secondary Text: `#475569` (slate-600)
    - Accent Brand: `#2563eb` (blue-600) / `#1d4ed8` (blue-700)
  - **Dark Mode (Obsidian Academic):**
    - Background: `#080c14` (deep midnight)
    - Surface Card: `#0f172a` (slate-900) / `#131c31`
    - Borders: `#1e293b` (slate-800)
    - Primary Text: `#f8fafc` (slate-50)
    - Secondary Text: `#94a3b8` (slate-400)
    - Accent Brand: `#3b82f6` (blue-500) / `#60a5fa` (blue-400)
    - Verification Accent: `#38bdf8` (sky-400) with subtle glow

## 2. Typography
* **Font Family:** `Inter`, `-apple-system`, `BlinkMacSystemFont`, `Segoe UI`, sans-serif.
* **Scale:**
  - Display: `3.5rem` (56px), `tracking: -0.03em`, `font-extrabold`
  - H1: `2.25rem` (36px), `tracking: -0.025em`, `font-bold`
  - H2: `1.75rem` (28px), `tracking: -0.02em`, `font-bold`
  - H3: `1.25rem` (20px), `font-semibold`
  - Body: `0.9375rem` (15px), `line-height: 1.6`
  - Captions/Badges: `0.75rem` (12px), `font-medium`

## 3. Elevation & Surfaces
* **Card Radii:** `12px` to `16px`.
* **Elevation Rule:** 1px border or subtle single-source shadow (`box-shadow: 0 4px 20px -2px rgba(0, 0, 0, 0.05)`).
* **Selection:** `bg-blue-600 text-white`.
* **Focus States:** `focus-visible:ring-2 focus-visible:ring-blue-500 focus-visible:ring-offset-2`.
